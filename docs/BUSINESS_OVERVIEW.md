# Business overview — Admin Panel

## Product

The **Admin Panel** is the internal operations console for university services staff. Operators manage **dormitory**, **food/catering**, **wallet/finance**, **ticketing**, **international applicants**, **business/shop**, and **organization** (roles & users) from one authenticated workspace.

## Who it serves

| Persona | Need |
| --- | --- |
| University admin / operator | Day-to-day lists, filters, approvals, and detail drawers |
| Branch / business staff | Scoped wallets, restaurants, dorms, tickets |
| Role requesters | Sign-in + staff/role selection and role request workflows |
| Support | Ticketing and request status |

## Core domains

| Domain | Examples |
| --- | --- |
| Authentication & org | OTP sign-in, staff selection, roles/menu, positions |
| Dormitory | Base info, residents, admissions, reservations, requests |
| Food / Catering | Restaurants, orders, food schedules |
| Wallet / Finance | Wallets, transactions, withdrawals, accounting |
| Ticketing | User & internal tickets |
| International | Applicants, basic info |
| Business / Shop | Businesses, products, orders |
| Shared reference data | Branches, provinces/cities, enums for selects |

## Success for operators

- Reach any module from the role-based sidebar  
- Filter lists with branch / status / date options that load reliably  
- Open detail drawers and complete approve / reject / return actions  
- Complete sign-in without depending on live OTP gateways (mock mode)
